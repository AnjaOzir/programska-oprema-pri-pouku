## Pregled snovi

| Vsebine  opis|
|---|---|
| Funkcije | Poimenovani bloki kode, ki jih lahko večkrat uporabimo. |
| Parametri in argumenti | Vrednosti, ki jih funkciji posredujemo ob klicu. |
| Vračanje vrednosti | Funkcija lahko z `return` vrne rezultat. |
| Klic funkcije | Funkcijo izvedemo tako, da napišemo njeno ime in po potrebi podamo argumente. |

## Ponovitev snovi iz osnovne šole

| Pojem | Primer ali razlaga |
|---|---|
| Spremenljivka | Ime za shranjeno vrednost, na primer `stevilo = 5`. |
| Podatkovni tipi | Števila, besedilo (nizi) in logične vrednosti (`True` ali `False`). |
| Računski operatorji | `+`, `-`, `*` in `/` uporabimo za računanje. |
| Pogoj | Z `if` izberemo, katera koda se izvede glede na pogoj. |
| Zanka | Zanka `for` ali `while` ponovi izvajanje kode. |
